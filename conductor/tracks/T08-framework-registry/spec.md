# T08 — Analytical framework registry and projections


## Objective
Create a versioned plug-in registry for analytical frameworks and validate framework-specific projections.

## Must requirements
- Each framework declares authoritative source/version, constructs, mapping schema, scoring/decision rules, uncertainty and applicability boundaries.
- Initial families: NSQHS/clinical governance, legal, evidence, human factors/sociotechnical, Safety-II/resilience, implementation science, consumer partnership, equity/cultural safety, rural/remote, workforce/scope, policy burden and readability/accessibility.
- Framework outputs remain separate projections unless constructs are demonstrably commensurable.
- Framework changes create new versions and trigger targeted invalidation/re-analysis rather than silent overwrite.
- Framework extraction/application has its own benchmark/adversarial fixtures.
