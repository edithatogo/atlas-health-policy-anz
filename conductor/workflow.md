# Workflow

1. Load deterministic context.
2. Select/create Conductor track.
3. Reconcile spec, plan and metadata.
4. Discover/reuse ecosystem capabilities before implementation.
5. Implement smallest coherent change.
6. Run context/dependency/source/citation/authentext validation as applicable.
7. Record evidence and unresolved limitations.
8. Commit with scoped message.
9. Update track status and changelog when maturity changes.
