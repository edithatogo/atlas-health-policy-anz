# Clinical Governance v0 Shadow Vertical Slice

This directory exercises the downstream Silver → Gold → Platinum → GraphRAG shape using source-grounded public-web observations while Bronze original bytes are unavailable in the current runtime.

It is intentionally **not a medallion release**. Its purposes are to test schemas, scope/authority handling, framework projection, GraphRAG construction and comparison presentation before Gate B opens.

## Important comparability limits

- Queensland's source is an allied-health clinical governance framework and must not be ranked as a whole-of-system equivalent.
- The NT source is Top End Health Service scoped and must not be treated as a whole-of-NT framework.
- Tasmania's public source in this slice is a THS system-governance/service-plan source that references governance structures; it is not a direct replacement for an underlying clinical governance framework.
- `not_determined` means the shadow observation did not establish the concept. It never means the concept is absent from the jurisdiction's policy corpus.
- The 2026 national model is a comparison/reference projection. Observed conceptual overlap is not a compliance judgment.

Production promotion is prohibited until original source bytes, exact reversible Silver spans, Gold assertion qualification and Platinum comparison gates pass.
