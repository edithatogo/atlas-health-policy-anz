# Ecosystem Reuse Contract

The project follows **reuse before build**.

Before implementing overlapping capability, inspect the ecosystem registry and classify candidate reuse as one of: `dependency`, `consume-contract`, `adopt-pattern`, `interoperate`, `evaluate`, or `reimplement-with-justification`.

The architectural archetypes are `archive-govt-nz` and `global-medicines-atlas`. SourceRight, CiteWeft and Authentext are required quality-toolchain dependencies. Git submodules are prohibited; integrations should be thin, versioned and contract-driven.
