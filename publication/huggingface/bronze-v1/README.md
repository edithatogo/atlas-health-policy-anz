# Australian Health Policy Atlas - Bronze

Public immutable source artefacts and capture/provenance records for Australian health policies, procedures, guidelines, directives and national comparators.

This directory is a **publication candidate contract**, not evidence that the remote dataset exists or that Bronze v1 is mature. Bronze release publication requires original captured payloads, fixity/provenance manifests, reconstruction checks, upload, and remote immutable-revision verification.
